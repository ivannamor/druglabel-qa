### Added
- Repo skeleton: settings module (`src/settings.py`), `.env.example`, folder structure.
- Free-tier provider setup on Google AI Studio: `gemma-4-31b-it` for generation, `gemini-3.5-flash-lite` as judge (fallback `gemini-3.1-flash-lite`), local open-source embeddings. Azure OpenAI kept as a config option.
- Data selection: `data/drug_list.csv` generated by rules from WHO ATC + openFDA (`notebooks/01_select_drugs.py`): 37 drugs, max 10 single-ingredient labels each (261 labels). First exploration in `notebooks/00_explore_openfda.py`.
- Bronze ingest notebook `notebooks/02_ingest_bronze.py`: raw openFDA labels → `bronze_labels` Delta table with run ID, openFDA data date, drug-list fingerprint and git commit.
