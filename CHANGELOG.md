# Changelog

All notable changes to this project. Format: [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added
- Repo skeleton: settings module (`src/settings.py`), `.env.example`, folder structure.
- Free-tier provider setup on Google AI Studio: `gemma-4-31b-it` for generation, `gemini-3.5-flash-lite` as judge (fallback `gemini-3.1-flash-lite`), local open-source embeddings. Azure OpenAI kept as a config option.
- Data selection: `data/drug_list.csv` generated by rules from WHO ATC + openFDA (`scripts/select_drugs.py`): 37 drugs, max 10 single-ingredient labels each (261 labels). First exploration in `scripts/explore_openfda.py`.
- Bronze ingest notebook `notebooks/01_ingest_bronze.py`: raw openFDA labels → `bronze_labels` Delta table with run ID, openFDA data date, drug-list fingerprint and git commit.
- First Bronze run (2026-10-14, Databricks Free Edition, serverless): 261 labels / 37 drugs → `workspace.druglabel_qa.bronze_labels` Delta version 0, run `db9eaa36-840a-47f4-866c-5dd4ee8a0570`, commit `6623d4d`. openFDA was reachable from Free Edition, so no offline fallback was needed.
- Silver chunking notebook `notebooks/02_chunk_silver.py`: `bronze_labels` (pinned Delta version) → `silver_chunks`, one row per chunk with `chunk_id = {label_id}:{section}:{n}`. 23 section fields kept, including clinical pharmacology, description and how supplied (used/not used and why: README "Label sections used"); split by numbered subsection, then sentence windows of ≤ 1200 chars with ≤ 150 chars overlap. openFDA child fields (e.g. `pregnancy`, old-format `drug_interactions`) are skipped when their parent section is present, to avoid duplicate and mislabeled chunks. `*_table` (HTML) fields are not used. Labels with no text in any kept section (empty in openFDA) are excluded and listed; a label with text but no chunks fails the run.
- First Silver run (2026-10-14): 14,131 chunks from 258 labels (202 PLR, 56 old format; 3 empty labels excluded) → `workspace.druglabel_qa.silver_chunks` Delta version 0, from `bronze_labels` version 0, run `403d583b-0e7a-42b2-a9b4-c6991d5968d4`, commit `8f7d719`.
- Gold embedding notebook `notebooks/03_embed_gold.py`: `silver_chunks` (pinned Delta version) → `gold_embeddings`, one 384-dim `bge-small-en-v1.5` embedding per chunk (`fastembed` 0.9.0, ONNX), computed on the chunk text with a context header (`drug (brand) · section · subsection`). Adds `text_hash` to detect identical passages across labels, and exports a parquet snapshot named after the Gold Delta version for local retrieval.
- First Gold run (2026-10-15): 14,131 embeddings (8,197 distinct passages) → `workspace.druglabel_qa.gold_embeddings` Delta version 0, from `silver_chunks` version 0, run `04c22471-8711-4189-95fc-f865db3588bf`, commit `409e2b0`. Embedding took 65 min (3.1 chunks/s on Free Edition serverless). The snapshot export in that commit failed after the table was written (pandas could not serialize Spark query metrics attached by `toPandas()`), so `exports/gold_v0.parquet` was written by re-reading the table version, as the notebook now does.
- Local setup for the Gold snapshot: Databricks settings in `src/settings.py` / `.env.example`, `scripts/pull_gold.py` (download, version check, sha256), `data/gold/` git-ignored.
- Vector retriever `src/retrieval/vector.py`: exact cosine search over the Gold snapshot (8,207 searchable passages after removing identical copies within a drug, ~15–50 ms per question), near-duplicate collapsing per drug and section (`DEDUP_THRESHOLD=0.95`, most recent label represents the group), `n_labels` per result. CLI: `python -m src.retrieval.vector "question"`. Local query embeddings match the Databricks ones (cosine 0.99999).
- Answer generation: `src/generation/llm.py` (one OpenAI-compatible client for Gemini, Azure OpenAI and OpenAI; retry with backoff, optional fallback model, Gemma `<thought>` stripping; records the model that actually answered), versioned prompt `prompts/answer_v1.md` (cite `[chunk_id]` after every fact, `NOT_IN_LABELS`, `PATIENT_SPECIFIC`), `src/generation/answer.py` (retrieve → prompt → LLM → citation check against the retrieved passages; returns prompt name and sha256). First answers: 4/4 correct on the test questions (2 answered with valid citations, 1 out-of-dataset refusal, 1 patient-specific refusal).

### Changed
- Generator switched from `gemma-4-31b-it` to `gemini-3.1-flash-lite` after measuring free-tier availability (Gemma 31B: HTTP 500 on every call for over a day; 26B: about half). Judge stays `gemini-3.5-flash-lite`; judge fallback removed (it was the new generator model). See README "LLM providers".
- Local one-off scripts moved from `notebooks/` to `scripts/` (`explore_openfda.py`, `select_drugs.py`); Databricks notebooks renumbered from 01. The first Bronze run (commit `6623d4d`) used the same code under its old name `notebooks/02_ingest_bronze.py`.
